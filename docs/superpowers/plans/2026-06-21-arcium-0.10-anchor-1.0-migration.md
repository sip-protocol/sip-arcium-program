# Arcium SDK 0.6.5 → 0.10.4 / Anchor 1.0.2 Migration Plan

> **For agentic workers:** This is a **compiler-driven dependency migration**, not a TDD feature build. There is no unit-test harness for this program (no bankrun/mocha unit layer); the only meaningful verification is `arcium build` (program `.so` + IDL + Arcis circuit compile) and, best-effort, `arcium test` (Docker localnet integration). Each task's "verify" step is therefore a build/check command with expected output — not a `write-failing-test-first` cycle. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Migrate `sip-arcium-program` from Arcium SDK `0.6.5` / Anchor `0.32.1` to Arcium `0.10.4` / Anchor `1.0.2`, preserving the program's behavior (3 MPC circuits + queue/callback instructions), so it builds + generates an IDL on the current host toolchain — completing the org-wide Anchor 1.0 alignment (#1161) for the third and last program.

**Architecture:** Pure version migration. The Arcis circuit source (`encrypted-ixs/src/lib.rs`) needs no code change (only the `arcis` dep bump). The Anchor program (`programs/sip_arcium_transfer/src/lib.rs`) needs ~6 mechanical edit classes derived verbatim from Arcium's per-version migration guides (0.6.3→0.7→0.8→0.9→0.10). TS scripts/tests need the `@coral-xyz/anchor`→`@anchor-lang/core` swap + the comp-def-init auth-arg drop. No on-chain redeploy in this PR (devnet redeploy is gated separately).

**Tech Stack:** Rust, Anchor 1.0.2, Arcium 0.10.4 (`arcium-anchor`/`arcium-client`/`arcium-macros`/`arcis` all `=0.10.4`), Arcis MPC circuits, `@arcium-hq/client` 0.10.4 (TS), Solana SBF, Docker (Colima) for the Arx-node localnet.

- **Program ID unchanged:** `S1P5q5497A6oRCUutUFb12LkNQynTNoEyRyUvotmcX9` (no new keypair; source-only migration).
- **Git:** GPG-signed commits (key `BF47B9DC1FA320FA`), conventional-commit messages, **no AI attribution**, **do NOT self-merge** — open a PR for RECTOR.
- **Behavior preserved:** identical instructions, circuits, events, errors. This is a migration, not a feature change.
- **Verification is build-driven:** "green" = `arcium build` succeeds (circuit + program + IDL). Localnet `arcium test` is best-effort (Docker); devnet redeploy is OUT OF SCOPE (gated).

### Task 3: `arcium build` green (the gate)

**Files:** iterate on `programs/sip_arcium_transfer/src/lib.rs`, `Anchor.toml`, Cargo files as the compiler dictates.

**Interfaces — Produces:** a compiling program `.so`, a regenerated IDL (`target/idl/sip_arcium_transfer.json`), and a compiled Arcis circuit — the migration's success criterion.

- [ ] **Step 1:** `cd <worktree> && arcium build 2>&1 | tee /tmp/arcium-build.log` (Docker daemon must be up; export `DOCKER_HOST` if needed).
- [ ] **Step 2 — resolve compiler errors against the research deltas, in priority order:**
  - **Missing LUT accounts** on `Init*CompDef` (e.g. "address_lookup_table not provided"): add to each of the 3 init structs:
    ```rust
    #[account(mut, address = derive_mxe_lut_pda!(mxe_account.lut_offset_slot))]
    /// CHECK: address lookup table, validated by address
    pub address_lookup_table: UncheckedAccount<'info>,
    #[account(address = LUT_PROGRAM_ID)]
    /// CHECK: address lookup table program
    pub lut_program: UncheckedAccount<'info>,
    ```
    (If instead the build errors that these are *already generated* by `#[init_computation_definition_accounts]`, do NOT add them.)
  - **Renamed symbol** (`init_computation_def`, an `ArgBuilder` method, a `derive_*` macro): use the exact name from the compiler error / `arcium-anchor` 0.10.4 docs.
  - **Stack-frame overflow** on a callback struct: `Box<>` its heavy accounts too.
  - **borsh / discriminant / dup-mutable** Anchor-1.0 nuances (per `reference_anchor-1.0-migration`): apply only if the compiler raises them (this program has no enums with explicit discriminants and no SPL CPI, so likely none).
- [ ] **Step 3 — re-run** `arcium build` until it exits 0. Confirm artifacts:
  ```bash
  ls -la target/deploy/sip_arcium_transfer.so target/idl/sip_arcium_transfer.json
  ```
  Expected: both exist; the IDL is non-empty JSON (proves the Anchor-1.0 IDL generator ran — the #1161 root-cause fix).
- [ ] **Step 4 — Commit** (first migration commit):
  ```bash
  git add programs/sip_arcium_transfer/Cargo.toml encrypted-ixs/Cargo.toml programs/sip_arcium_transfer/src/lib.rs Anchor.toml Cargo.lock
  git commit -S -m "chore(sip-arcium): migrate to Arcium 0.10.4 / Anchor 1.0.2 (program)"
  ```
